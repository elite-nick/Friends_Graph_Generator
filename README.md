# Friends Graph Generator
Создай схему взаимоотношений всех своих друзей!

<img width="1920" height="945" alt="image" src="https://github.com/user-attachments/assets/849cf384-b3f6-4f87-ad44-630a5e451490" />

**Python-скрипт для визуализации взаимоотношений всех своих друзей с кастомизацией и импортом/экспортом своего проекта!**

## Для чего я сделал этот скрипт?
В интернете я находил такие визуализаторы, но они то работали в одну сторону, либо были ограничены. Я решил сделать проект, который давно хотел, но руки не доходили...

## Возможности скрипта

- Добавление любого количества друзей
- Быстрая смена аватарки и имен
- Удобное отображение линий
- Возможность перемещать друзей и линии в визуализаторе
- Импорт/Экспорт проекта

## Подготовка к запуску

- Установите зависимость flask (**pip install flask**)
- Скачайте весь этот проект

## Запуск
Просто запустите скрипт (**python main.py** или **start.bat**) и в любом браузере откройте **http://127.0.0.1:5000/**!
